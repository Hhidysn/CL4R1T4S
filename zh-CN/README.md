## 上游 README 译文

为所有人提供 AI 系统的透明度与可观测性！完整提取自 OpenAI、Google、Anthropic、xAI、Perplexity、Cursor、Windsurf、Devin、Manus、Replit 等的系统提示词、指导方针和工具——几乎涵盖所有主流 AI 模型与智能体！ 

📌 为何存在此项目

    “为了信任输出，必须理解输入。”

AI 实验室通过庞大且未被公开的提示词脚手架来塑造模型的行为方式。由于 AI 正在成为越来越多人类所信任的外部智能层，这些隐藏的指令可能会影响公众的认知和行为。

这些提示词定义了：

    AI 不能说什么

    它们被迫遵循什么人设和功能

    它们被告知如何撒谎、拒绝或转移话题

    以及默认融入了哪些伦理/政治框架

    如果你在不知道其系统提示词的情况下与 AI 交互，
    你并不是在与一个中立的智能对话——而是在与一个提线皮影交谈。

CL4R1T4S 旨在为此提供帮助。
